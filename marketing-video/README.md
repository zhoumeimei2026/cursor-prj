面向「内窥镜主控板 + 影像系统定制开发团队」的 5 秒宣传短片（1920×1080 / 30fps / 带背景音）。

## 成片

- `endoscope_marketing_5s.mp4` — 最终成片（5.0 秒，1080p，H.264 + AAC）

## 画面结构（共 5 秒）

场景之间使用 0.4s 交叉淡入淡出（crossfade）衔接，并叠加了一段轻柔的环境音垫。

## 素材

`assets/` 中的三张底图（主控板 / 影像系统 / 品牌背景）为 AI 生成的无文字底图，
所有中文文案均由 `ffmpeg drawtext` 在合成阶段叠加，方便随时修改。

## 重新生成

```bash
bash build.sh
```

依赖：`ffmpeg`（需含 `libx264` 与 `drawtext`/freetype）以及一款 CJK 字体
（脚本默认使用 `WenQuanYi Micro Hei`）。

## 自定义

直接修改 `build.sh`：

- **文案**：各 `drawtext=...:text='...'` 字段
- **时长 / 节奏**：顶部的 `D1` / `D2` / `D3`（场景时长）与 `XF`（转场时长）
- **配色**：`ACCENT`（强调色）
- **字体**：`FONT` 环境变量，例如 `FONT=/path/to/your.ttf bash build.sh`
- **分辨率 / 帧率**：`W` / `H` / `FPS`

> 提示：替换 `assets/` 下的底图即可换成你们自己的实拍/渲染画面（建议 16:9，
> 横向 ≥1920px），无需改动脚本即可重新合成。
